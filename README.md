🐊 This is an unofficial AREDL discord bot that was made for the University of Florida Geometry Dash organization 🐊

✅ This bot is known about and permitted by AREDL admins and developers ✅

This bot has different capabilities than the official AREDL discord server bot, which can be found in this repo:
    - https://github.com/All-Rated-Extreme-Demon-List



⭐ This discord bot allows users to search through AREDL leaderboards globally, by country, or within a discord server.  This allows a user in a less popular discord server to find their ranking and see how they compare in skill to others within the server! ⭐

✨ In order to see the global leaderboard type: /aredlleaderboards ✨

🌍 Afterward, choose global, country, or server for the scope of the search! 🌎

🏠 Server-wide leaderboards currently only work with users registered to AREDL through discord 🏠

🔥 Finally, choose how to sort the list!  You can currently sort by points, extreme demon count, or by hardest level 🔥



If you think this idea is unique and you want to gain experience working with APIs, please feel free to contribute!  Any contributions are welcome!



⚠️ All information in this bot is pulled from the All Rated Extreme Demon List (AREDL) API.  Any inaccuracies are unintentional ⚠️
